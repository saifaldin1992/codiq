## النطاق المنفذ مقابل متطلبات الخطة

| المتطلب الرسمي | التنفيذ |
|---|---|
| plans → plan_features → merchant_subscriptions | هجرة `20260825150000_phase16_plans_entitlements` بقيد فريد جزئي (اشتراك نشط واحد لكل تاجر) وبذر الخطط الثلاث وbackfill كل التجار القائمين على «المجانية» |
| entitlement resolver واحد | `entitlement.service.ts`: استخدام حي من القاعدة + `assertWithinPlanLimit` داخل معاملة العملية؛ تجاوز الحد = `403 PLAN_LIMIT_EXCEEDED` برسالة عربية باسم الخطة وحدّها |
| لوحة المالك | إدارة الخطط (سعر + حدود لكل ميزة، تسري فوراً) وقائمة التجار بخطتهم مع إسناد/ترقية يدوية نافذة فوراً |
| لوحة التاجر | `SubscriptionPanel` في إعدادات/الاشتراك: الخطة الحالية وأشرطة الاستهلاك الحية لكل حد (تنبيه بصري عند ≥80%) |
| استبدال الحد المؤقت للمتاجر | `MAX_STORES_PER_MERCHANT` أزيل؛ إنشاء المتجر يمر بالمحلّل (المجانية=3 تحفظ السلوك التاريخي)؛ حُدّث تأكيد S13-07 للرمز الجديد كما نصّت الخطة |
| خطة Free افتراضية تلقائية | backfill في الهجرة + اشتراك تلقائي داخل معاملتي التسجيل الذاتي والإضافة اليدوية |
