# بوابة المرحلة 10 — مسار الخادم الإنتاجي وملفات القالب

**الحالة:** تدقيق مكتمل؛ لا حذف قبل مراجعة هذه البوابة.

## مسار الإنتاج الفعلي

| الطبقة | الدليل | النتيجة |
|---|---|---|
| نقطة التشغيل | `package.json` → `build` يحزم `server/index.ts` و`start` يشغّل `dist/index.js`. | هذا هو مسار خادم الإنتاج. |
| واجهة API | `server/index.ts` يستورد `createApp` من `phase1-backend/src/http/app.ts` ويركبه تحت `/api`. | Express/Prisma CODIQ فقط. |
| واجهة الويب | `server/index.ts` يخدم `dist/public` ثم يعيد `index.html` لمسارات SPA. | لا tRPC ولا OAuth قالب في الخادم. |
| tRPC/OAuth/StorageProxy | لا يوجد `server/_core/` حالياً، و`server/` يحتوي `server/index.ts` فقط، ولم يُعثر على ملفات أو imports باسم `trpc` أو `oauth` أو `storageProxy` في مسار الخادم. | لا ملفات قالب خادم مرشحة للحذف. |

## قائمة الحذف المرشحة

> **فارغة.** لا يوجد ملف `server/_core` أو ملف قالب خادم آخر في المستودع الحالي يمكن حذفه دون اختراع عملية تنظيف غير موجودة.

## بنود التصلب التالية بعد اجتياز البوابة

| البند | الدليل الحالي | التعديل المحدود المقترح |
|---|---|---|
| المنفذ | لا توجد دالة `findAvailablePort`؛ لكن `server.listen` لا يعرض رسالة تشغيلية صريحة عند `EADDRINUSE`. | إضافة معالج خطأ يطبع رسالة واضحة ويفشل الإقلاع من دون تبديل المنفذ. |
| JSON | `phase1-backend/src/http/app.ts` يستخدم `express.json()` بلا حد صريح. | ضبط `express.json({ limit: "1mb" })`. |
| دليل التشغيل | الاختبارات القديمة تحتاج خادماً مركباً لخدمة SPA و`/api` معاً. | اختبار بدء الخادم المركب ونجاح `/api`، ثم محاولة ثانية على نفس المنفذ تثبت رسالة الفشل. |

## القرار المطلوب

> قائمة الحذف فارغة. هل توافق على تنفيذ تصلب المنفذ وحد JSON والدليل التشغيلي فقط، من دون حذف ملفات قالب؟
