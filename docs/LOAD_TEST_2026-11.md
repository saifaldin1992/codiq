# اختبار الحمل — 2026-11-20

**ماذا قِيس:** قدرة **الأصل** (خادم Node واحد + PostgreSQL محليّ) على أكثر نقاط المتجر طلباً، **بلا CDN أمامه** — أسوأ حالة.
**الجهاز:** 4 أنوية vCPU و15 GiB، يتقاسمها الخادم وPostgreSQL وأداة الحمل نفسها. **الأداة:** autocannon 8، 50 اتصالاً متزامناً، 20 ثانية لكلّ سيناريو.
**البيانات:** متجر تجريبيّ بـ12 منتجاً (`pnpm demo:seed`). **النسختان:** الشيفرة الأصليّة كما رُفعت (`d22a5e5`) والحاليّة.

| السيناريو | الأصليّة req/s | الحاليّة req/s | p50 (أصليّة → حاليّة) | p99 الحاليّة | أخطاء |
|---|---:|---:|---|---:|---:|
| `public-config` (إعدادات المتجر، ٧ استعلامات) | 301 | 317 | 164 → 155 ms | 211 ms | 0 |
| قائمة المنتجات (24) | 500 | 503 | 99 → 98 ms | 134 ms | 0 |
| صفحة منتج | 508 | 516 | 98 → 96 ms | 116 ms | 0 |
| التصنيفات | 841 | 855 | 59 → 58 ms | 75 ms | 0 |
| **نبضة الزيارة (POST)** | **768** | **1,509** | **63 → 32 ms** | 53 ms | 0 |

**صحّة العدّاد المجمّع تحت الحمل:** قبلت الأداة 30,189 نبضة وسجّلت القاعدة 30,239 زيارة — الفرق 50 هو بالضبط الطلبات الخمسون التي كانت في الطريق عند انتهاء نافذة القياس. لا زيارة ضاعت ولا تكرّرت.

## ما يعنيه هذا

- **النبضة تضاعفت** لأنّ كلّ مشاهدة صارت بلا كتابة في القاعدة (تجميع في الذاكرة + حدّ معدّل في الذاكرة).
- **القراءات لم تتغيّر على الأصل — وهذا متوقّع.** مكسبها في التخزين على حافّة Cloudflare (`s-maxage=60`): حين تُفعَّل قاعدة التخزين،
  يصل الأصلَ طلبٌ واحد لكلّ رابط كلّ دقيقة لكلّ نقطة حضور، مهما كان عدد الزوّار. هذا **لم يُقَس هنا** — يحتاج نشراً حقيقياً.
- **تقدير السعة (غير مقيس):** صفحة متجر تطلب نحو ٤–٦ نداءات API. بلا CDN، نسخة واحدة بهذا الحجم تخدم قرابة **١٠٠ زائر جديد في الثانية**
  قبل أن ترتفع الأزمنة. مع CDN يصير الحدّ الأدنى ما لا يُخزَّن: السلّة والشراء والدخول.
- **عنق الزجاجة التالي:** `public-config` (٧ استعلامات لكلّ تحميل صفحة). يستحقّ تخزيناً في الذاكرة لثوانٍ داخل الخادم نفسه إن ظهر في القياس الحقيقيّ.

## الإعادة

```bash
pnpm build
CODIQ_DEMO_MODE=true CODIQ_POSTGRES_URL=…/codiq_demo_x pnpm demo:seed     # اسم القاعدة يجب أن يحتوي demo
NODE_ENV=production PORT=4100 CODIQ_TRUSTED_EDGE=cloudflare … node dist/index.js
npx autocannon@8 -c 50 -d 20 http://127.0.0.1:4100/api/store/demo-store/products?limit=24
```
لنبضة الزيارة: أرسل `CF-Connecting-IP` عشوائياً لكلّ طلب، وإلّا يوقفك حدّ ٣٠٠ نبضة/١٠ دقائق لكلّ عنوان (وهذا مقصود).
