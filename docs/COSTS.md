### ترتيب التجاوز — وهذا هو الجواب الحقيقيّ

```
الآن       ← GitHub     (كم تبرمج، لا كم تاجراً عندك)
الآن       ← Railway    (كم ساعةً تعمل خدمتك)
١٥ تاجراً   ← Resend     ★ أوّل تجاوزٍ يقوده التجّار فعلاً
٢٠ تاجراً   ← Neon       ← أو ٦٠ بتفعيل حافّة Cloudflare
٦٦٠        ← R2
+١٠٠٠      ← Sentry
أبداً       ← النطاق
```

**وثلاث ملاحظات تستحقّ الانتباه:**

**١. أوّل بندين لا علاقة لهما بالتجّار.** تاجرٌ واحد أو مئة: الرقم نفسه. ولهذا
تجاوزتَهما قبل أن يكون عندك تاجرٌ واحد حقيقيّ.

**٢. Cloudflare تُضاعف مهلة Neon ثلاث مرّات** — وهذا رقمٌ محسوب لا رأي:

```
بلا الحافّة:  زيارات الواجهات تُوقظ القاعدة  →  ٢٠ تاجراً
مع الحافّة:   الزيارات تُخدَم من الحافّة      →  ٦٠ تاجراً
                                                  ↓
                        ساعةُ عملٍ تشتري أربعين تاجراً على المجانيّ
```

**٣. Resend أوّل ما سيلدغك — عند خمسة عشر تاجراً.** وهو قريبٌ جداً، وزبونك لا يقرأ
البريد أصلاً. فترتيب الأولويّات صار بالأرقام لا بالرأي: **(أ)** فعّل Cloudflare ←
يشتري ٤٠ تاجراً · **(ب)** احسم واتساب ← يحذف أوّل بندٍ يتجاوز · **(ج)** ثمّ Neon
Launch عند ~٦٠.

## ٢. Neon — كيف تُحسَب بالضبط

**الوحدة `CU-hour`. وCU = نواةٌ واحدة + ٤ غيغا رام.**

```
الفاتورة = (CU × ساعات الاستيقاظ × $0.106)
         + (غيغا مخزَّنة × $0.35)
         + (غيغا استعادة فورية × $0.20)
```

**والمِفتاح الذي يقرّر كلّ شيء: لا تُحاسَب على الاستعلامات بل على الاستيقاظ.**

> **أيّ استعلامٍ يُبقي القاعدة مستيقظةً خمس دقائق بعده.**

فاليوم **٢٨٨ نافذة** من خمس دقائق، والسؤال ليس «كم استعلاماً؟» بل «كم نافذةً فيها
نشاط؟»:

| الحالة | نوافذ | الكلفة |
|---|---|---|
| استعلامٌ واحد | ١ | `$0.0022` |
| **١٠٠٠ استعلام في الدقائق الخمس نفسها** | **١** | **`$0.0022`** |
| ١٠٠ استعلام موزّعة على اليوم | ١٠٠ | `$0.22` |

**والعمل نفسه شبه مجّانيّ.** معاملة الدفع — `Serializable` وأقفال وحسابات مالية
وصندوق صادر — أثقل ما في المنصّة وتستهلك ~٠٫٢ ثانية معالجة:

```
١٠٠٠٠٠ طلب × 0.2 ثانية = 5.5 CU-hour = $0.58
```

**نصف دولارٍ لمئة ألف عملية دفع.** فالفاتورة ثمنُ الساعات الفارغة لا ثمنُ العمل.

### ولهذا وقع الانقطاع

```
outbox-worker.ts:493   استعلامٌ كلّ ٥ ثوانٍ  →  ٢٨٨/٢٨٨ نافذة  →  ٢٤ ساعة/يوم
```

**اثنا عشر ألف سؤالٍ يومياً جوابها «لا شيء».** صفر عمل، وحصّةٌ كاملة. والمقيس
**[مقيس]**: `production` ٥٤٫٣ CU-h + `staging` ٥٦٫٣ = **١١٠٫٦ > ١٠٠ المسموحة**.

### أيّ درجة تشترك

| | الحكم |
|---|---|
| **Free** (١٠٠ CU-h) | يكفي حتى ~٤٠ تاجراً نشطاً **بعد** إصلاح العامل |
| **Launch** `$0.106` | ✅ **هذه درجتك عند الإطلاق** — متوقَّع `$10–20` |
| **Scale** `$0.222` | ⛔ ضعف السعر. لـ٥٦ CU وSLA ونسخِ قراءة — **لا تحتاجها قبل آلاف التجّار** |

## ٣. R2 — كيف تُحسَب، ولماذا هي بطلك الصامت

```
الفاتورة = max(0, غيغا − 10) × $0.015          ← تخزين
         + max(0, كتابات − 1م) ÷ 1م × $4.50    ← Class A
         + max(0, قراءات − 10م) ÷ 1م × $0.36   ← Class B
         + 0                                    ← ★ الخروج مجّانيّ دائماً
```

**السطر الأخير هو كلّ الحكاية.** على مزوّدٍ آخر، متجرٌ تُزار صوره مليون مرّة يولّد
فاتورة نطاقٍ تردّديّ بمئات الدولارات. **عند Cloudflare: صفر، إلى الأبد.**

| الحجم | التخزين | الفاتورة |
|---|---|---|
| ١٠٠٠ متجر × ٣٠ صورة | ١٢ غيغا | **`$0.03`** |
| ١٠٠٠٠ متجر | ١٢٠ غيغا | **`$1.65`** |
| ١٠٠٠٠٠ متجر | ١٢٠٠ غيغا | **`$17.85`** |

**ومئة ألف متجرٍ بصورها كلّها = أقلّ من عشرين دولاراً.** هذا أذكى اختيارٍ في بنيتك.

## ٤. Railway — كيف تُحسَب

```
الفاتورة = $5  +  max(0, (غيغا-ساعة رام × سعرها) + (نواة-ساعة × سعرها) − $5)
```

**تُحاسَب على زمن التشغيل × الحجم**، لا على الطلبات. وخدمةٌ تعمل ٢٤ ساعة بنصف
غيغا رام تكلّف نحو `$5`/شهر.

**[مقيس]:** خدمةٌ واحدة استهلكت `$4.02` من `$5` المشمولة، والفاتورة `$0.09`.

**وHobby يشمل ٨ غيغا رام و٨ أنوية و١٠٠ غيغا قرص** — يكفي **آلاف التجّار**. لا
ترقِّ لأجل السعة.

## ٥. GitHub — لا تنمو مع التجّار

```
الفاتورة = $4  +  max(0, دقائق − 3000) × $0.008
```

**تنمو مع نشاطك التطويريّ لا مع منصّتك.** دورة CI كاملة ~١٩ دقيقة، فـ**٣٠٠٠
دقيقة ≈ ١٥٨ دورة شهرياً**.

**[مقيس]:** `$30.28` gross على مستودع CODIQ هذا الشهر ≈ **٣٧٨٥ دقيقة** — أي
تجاوزتَ المشمول، والصافي ~`$6` يغطّيه سقف الـ`$20`.

> **اقرأ `Net` لا `Gross`** في صفحة الفوترة.

**وأرخص ثلاث حيَل:** لا تدفع إلا بتغييرٍ مكتمل · اجمع تغييرين في طلبٍ واحد ·
وتحقّق محلياً أوّلاً (`tools/local-ci/` يعطيك ١١٢ فحصاً بصفر دقيقة).

## ٦. ⭐ ألف تاجر على **خطّتك المجانية** — الحالة التي سألتَ عنها

هذا سؤالٌ اقتصاديّ لا تقنيّ، وجوابه مطمئن.

**الفرضيّات:** ١٠٠٠ تاجر · متجرٌ لكلٍّ · ٣٠ منتجاً بصورة · **٢٠٪ نشطون** بعشرين
طلباً شهرياً = **٤٠٠٠ طلب** · و٥٠٠ ألف زيارة واجهة.

| البند | الحساب | الكلفة |
|---|---|---|
| R2 | ١٢ غيغا + قراءات | `$0.21` |
| Neon | مستيقظة ~٨ ساعات/يوم = ٦٠ CU-h | `$7.06` |
| Railway | ٠٫٢ طلب/ثانية | `$10` |
| Resend | ٨٠٠٠ رسالة > ٣٠٠٠ | `$20` |
| GitHub + نطاق | ثابت | `$5` |
| Sentry · Cloudflare | داخل المجانيّ | `$0` |
| **الإجمالي** | | **~`$42`/شهر** |

### والدخل من هؤلاء «المجانيّين»

**خطّتك المجانية ليست مجانيّةً عليك — هي مموَّلةٌ بالعمولة** (٣٠٠ نقطة أساس):

```
٤٠٠٠ طلب × ٣٠٠٠٠ دينار × ٣٪  =  ٣٦٠٠٠٠٠ دينار  ≈  $2,750 /شهر
الكلفة                                              ≈  $42
                                                        ↓
                                                 هامش ٩٨٫٥٪
```

### وأسوأ حالة: ألف تاجرٍ **نائم** بصفر طلب

| البند | الكلفة |
|---|---|
| تخزين صفوفهم وصورهم | `$0.25` |
| Neon (لا طلبات، لكن زحفُ محرّكات البحث يوقظها) | `$5–19` |
| Railway | `$5` |
| **الإجمالي** | **~`$15–30`/شهر بصفر دخل** |

**وهذا هو الخطر الحقيقيّ للخطة المجانية** — لا الحوسبة بل **واجهاتٌ تُزحف ولا
تبيع**. وعلاجه بندٌ واحد:

> **تفعيل حافّة Cloudflare.** ألف واجهةٍ تُخزَّن على الحافّة فلا تصل Railway ولا
> Neon أصلاً. **فكثرة المتاجر هي أقوى حجّةٍ لتفعيلها** — لا CDN للترف بل حاجزٌ
> يمنع ألف متجرٍ نائم من إيقاظ قاعدتك.

## ١٠. مقترح: شاشة «استهلاك المنصّة» في لوحة المالك

**طلبها المالك في 2026-09-12،** والسبب وجيه: الأرقام أعلاه تتغيّر كلّ شهر، ووثيقةٌ
تُحدَّث باليد تكذب بعد أسبوعين.

### القاعدة التي تحكم التصميم

> **تقيس المنصّة نفسها، ولا تسأل مزوّداً عن فاتورته.**

قراءة فواتير Railway وNeon وCloudflare تحتاج **رموزاً** لكلٍّ منها، وهي أسرارٌ
تُخزَّن وتُدوَّر وتُسرَّب. والمنصّة **تعرف استهلاكها من قاعدتها** — فتقيس ما تعرفه
وتضرب في أسعارٍ مضبوطةٍ في الإعدادات.

**وتُعرَض حقيقتان منفصلتان بوضوح:**

| | |
|---|---|
| **الاستهلاك** | حقيقةٌ مقيسة من القاعدة — لا تقدير |
| **الكلفة المقدَّرة** | مشتقّةٌ بضرب الاستهلاك في سعرٍ مضبوط |

**ولا تُسمّى الثانية «فاتورة» أبداً.** من يقرأ رقماً مشتقّاً كأنّه فاتورة يبني عليه
قراراً خاطئاً — وهذا درس ق-189 نفسه: رقمٌ يطمئن بلا أن يكون صحيحاً أخطر من غيابه.

### العدّادات — كلّها موجودةٌ في المخطّط اليوم

| المقياس | المصدر | يقود |
|---|---|---|
| طلبات الشهر · المكتملة · الملغاة | `store_orders` | Neon · Railway |
| **بايتات الصور** | **`product_images.byte_size`** | R2 |
| **زيارات الواجهات اليومية** | **`StoreVisitDaily`** (ق-202) | Cloudflare · Railway |
| الرسائل المُرسَلة | `notification_outbox` | Resend |
| **العمولة المكتسَبة** | **`ledger_entries`** | ← الدخل الحقيقيّ |
| حجم القاعدة | `pg_database_size()` | Neon تخزين |
| تجّار نشطون / نائمون | `merchants` · `stores` | خطر الخطة المجانية |

**لا جدول جديد ولا هجرة.** كلّ ما تحتاجه الشاشة مقروءٌ ممّا هو مكتوبٌ أصلاً.

### ما تعرضه

**١. الشهر الحالي:** استهلاكٌ مقيس · كلفةٌ مقدَّرة لكلّ خدمةٍ من السبع · والعمولة
المكتسَبة مقابلها.

**٢. الرقم الواحد الذي يقرّر:**

```
الهامش = (العمولة المكتسَبة − الكلفة المقدَّرة) ÷ العمولة
```

**٣. كلفة الطلب** — تنزل وأنت تنمو، وهي أبلغ ما يراه مالكٌ على شاشة.

**٤. ⭐ الأهمّ تجارياً — التجّار النائمون:**

> عددهم · ما يكلّفونه · وصفر دخلهم. **وهذه أداةٌ لا يملكها اليوم:** أن يرى أنّ
> ثلاث مئة تاجرٍ مجانيّ لم يُكملوا طلباً واحداً منذ شهرين، فيقرّر — دعوةً أو
> تنبيهاً أو إطفاءً.

**٥. جرسُ إنذار الحصّة:** «Neon: ٧٨ من ١٠٠ ساعة» — فلا يتكرّر انقطاع 2026-09-09
بلا سابق إنذار.

### التكلفة والنطاق

**يومٌ واحد.** خدمةٌ تجمع العدّادات · مسارٌ واحد للمالك بصلاحية `finance.view` ·
شاشةٌ واحدة · وأسعارٌ في `platform_settings` يعدّلها المالك حين يغيّر مزوّدٌ سعره.

**وحارسٌ يلزمها:** أن يظلّ كلّ رقمٍ معروضاً **مقروءاً من القاعدة أو مشتقّاً بسعرٍ
معلَن** — فلا يتسلّل رقمٌ ثابتٌ مكتوبٌ بخطّ اليد إلى شاشةٍ تُتَّخذ عليها قرارات.
