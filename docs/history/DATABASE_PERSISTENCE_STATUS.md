# حالة قاعدة البيانات واستمرارية البيانات

**تاريخ المراجعة:** 18 أغسطس 2026  
**الحالة:** قاعدة التطوير موجودة وتعمل؛ لم تُهيأ بعد قاعدة إنتاج دائمة.

## الوضع الحالي

يستخدم CODIQ قاعدة PostgreSQL قياسية باسم `codiq_phase5` في بيئة التطوير المحلية. يتصل التطبيق بها عبر Prisma وهجرات SQL قابلة للنقل، وفق المبدأ الملزم للمشروع الذي يعتمد PostgreSQL وS3-compatible ولا يربط البيانات ببيئة استضافة واحدة.

| عنصر المراجعة | النتيجة |
|---|---|
| محرك البيانات | PostgreSQL قياسي. |
| حجم قاعدة التطوير وقت الفحص | 9119 kB. |
| سجل الهجرات | 5 هجرات Prisma مطبقة. |
| الجداول التشغيلية الموجودة | هويات المالك والتاجر والزبون، المتاجر، المنتجات، المخزون، الطلبات، عناصر الطلب، سجل أحداث الحالة، والجلسات. |
| بيانات موجودة | توجد سجلات حالية في جداول الحسابات والمتاجر والمنتجات والطلبات وسجل حالات الطلب. |
| حفظ الوسائط | مراجع بيانات الصور فقط؛ لا تُحفظ البايتات داخل PostgreSQL. |

## الفرق بين التطوير والإنتاج

قاعدة `codiq_phase5` مناسبة للتطوير والاختبارات الحالية، لكنها تعمل داخل بيئة التطوير ولا ينبغي اعتبارها مخزن الإنتاج الدائم لموقع منشور. يلزم ربط النشر النهائي بقاعدة PostgreSQL دائمة مستقلة ذات قرص محفوظ ونسخ احتياطي، ثم تمرير اتصالها من خلال متغير بيئة `DATABASE_URL` من دون وضع السر في المستودع أو الكود.

| جانب | التطوير الحالي | الإنتاج المطلوب |
|---|---|---|
| الموقع | PostgreSQL محلي | مثيل PostgreSQL دائم منفصل. |
| الاستمرارية | ضمن دورة بيئة التطوير فقط | قرص دائم ونسخ احتياطي ومراقبة. |
| الأسرار | اتصال تطوير محلي | `DATABASE_URL` آمن في إعدادات البيئة فقط. |
| التهيئة | هجرات Prisma موجودة | تشغيل الهجرات نفسها على قاعدة الإنتاج قبل بدء الموقع. |
| نقل البيانات | بيانات اختبار قابلة للمسح | استيراد مدروس أو بدء فارغ حسب قرار المالك. |

## الإجراء التالي المطلوب

لتفعيل الحفظ الدائم، نحتاج اختيار أو توفير قاعدة PostgreSQL إنتاجية قياسية. يمكن أن تكون خدمة PostgreSQL مُدارة أو خادماً ذاتياً، بشرط وجود TLS ونسخ احتياطية منتظمة وحساب تطبيق محدود الصلاحيات. بعد توافر رابط الاتصال، يضاف عبر إدارة الأسرار، وتطبق الهجرات الحالية، ثم ينفذ اختبار إنشاء وقراءة بيانات غير حساسة للتحقق من الاستمرارية.

> لا تُنقل بيانات الاختبار الحالية إلى الإنتاج تلقائياً. يحدد مالك المنصة صراحةً ما إذا كانت قاعدة الإنتاج تبدأ فارغة أو تستورد بيانات محددة بعد مراجعتها.
